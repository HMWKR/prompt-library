```
P0 이슈: AI 패널이 모바일(320-480px)에서 전체 화면을 차지하고 워크스페이스가 숨겨지는 문제. 하단 시트 패턴으로 해결해줘.
```

## 프롬프트 분석

- **해석**: w-80 고정 너비가 모바일에서 전체 화면을 차지하는 P0 이슈 해결
- **작업 유형**: convergent

## 최적화된 프롬프트

```
AIPanel과 QuickAccessPanel을 하단 시트 패턴으로 수정해줘:
- 모바일: fixed bottom-0, h-[70vh], rounded-t-3xl, z-50
- md 이상: relative, h-full, w-80 (기존 사이드 패널)
- 모바일 핸들바 추가 (드래그 힌트)
- ARIA 접근성: role="dialog", aria-modal="true"
```

**개선 포인트**:
- 브레이크포인트별 구체적 CSS 명시
- 접근성 요구사항 추가

**사용된 기법**: role-prompting
